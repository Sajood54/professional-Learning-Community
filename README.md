# مجتمع التعلم المهني
## التكامل بين المهارات الرقمية والرياضيات في تنمية التفكير الرياضي وتحليل البيانات

هذا المستودع مرجع عملي لتخطيط وتنفيذ وتوثيق مجتمع تعلم مهني يضم معلمة المهارات الرقمية ومعلمات الرياضيات، بهدف توظيف الأدوات الرقمية في تدريس الرياضيات وتحسين تعلم الطالبات استنادًا إلى البيانات والأدلة.

### دورة العمل
1. تشخيص تعلم الطالبات وتحديد مهارة رياضية ذات أولوية.
2. تصميم تدخل تعليمي مشترك يوظف أداة رقمية مناسبة.
3. تنفيذ التدخل وجمع الشواهد.
4. مقارنة النتائج القبلية والبعدية وتحليلها.
5. اتخاذ قرار التحسين وتوثيق الممارسة.

### ملاحظة تنظيمية
تُستكمل بيانات المدرسة والتواريخ وأسماء المشاركات وأعداد الطالبات والنتائج الفعلية عند التنفيذ. النماذج الواردة قوالب قابلة للتحرير، ولا تتضمن نتائج ميدانية مفترضة.

### خصوصية البيانات
لا تُرفع أسماء الطالبات أو أرقام هوياتهن أو بياناتهن الشخصية إلى المستودع. تستخدم رموزًا أو بيانات مجمعة ومجهّلة عند توثيق النتائج.
